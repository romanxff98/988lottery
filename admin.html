📲 วิธีทำงานของระบบ

1. ลูกค้าจองสลากในเว็บ → ระบบเปิด LINE พร้อมรายละเอียดออเดอร์ให้อัตโนมัติ
2. ลูกค้าส่งข้อความ + รูปสลิปมาทาง LINE (@797cgrbe)
3. แอดมินตรวจสลิป แล้วกด ➕ เพิ่มออเดอร์ ในแท็บ "คำสั่งซื้อ" เพื่อบันทึกเข้าระบบ
4. กด ✓ ยืนยัน เมื่อเช็คเงินเข้าแล้ว ลูกค้าจะเห็นสถานะอัปเดตในหน้าประวัติการซื้อของตัวเอง (เครื่องเดียวกัน)
